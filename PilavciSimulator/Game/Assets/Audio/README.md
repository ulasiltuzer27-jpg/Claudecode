# Ses değiştirme

- **Efektler:** `Sfx/<id>.wav` koyarsanız o efektin prosedürel sentezi yerine
  dosya çalınır. Kimlikler: `ui_click`, `ui_open`, `ui_close`, `ui_error`, `coin`, `cash`,
  `pickup`, `place`, `drop`, `knob`, `lid`, `plate`, `scoop`, `pour_rice`, `pour_water`,
  `sizzle`, `salt`, `pepper`, `stir`, `serve`, `bad`, `tip`, `levelup`, `achievement`,
  `whistle`, `meow`, `purr`, `seagull`, `horn`, `van_horn`, `splash`, `wash`, `shred`,
  `ignite`, `money_bad`, `shutter`, `eat`, `bell`, `step1`..`step4`.
- **Döngüler:** `amb_city`, `amb_sea`, `amb_rain`, `amb_night`, `amb_crowd`, `loop_boil`,
  `loop_sizzle`, `loop_flame`, `loop_water`, `loop_stir`. Aynı adla `.wav` olarak
  bırakın; dosya döngüsel çalınır.
- **Müzik:** `Music/*.ogg` dosyaları menüde ve oyunda sırayla çalınır. Ses düzeyi
  Ayarlar → Ses → Müzik'ten ayarlanır.
