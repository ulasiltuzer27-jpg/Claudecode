# Ornek Mod

Bu klasor, madde 25'teki Workshop paket bicimini gosterir.

- `mod.json` zorunlu. Olmayan klasor mod sayilmaz.
- Yalnizca `.json` ve `.png` dosyalari icerik olarak taranir; bu README
  gibi diger dosyalar yok sayilir (ama modun yuklenmesini engellemez).
- Modlar KOD CALISTIRMAZ.

Aktif mod kumesi bir PARMAK IZI uretir ve bu, karsilama mesajiyla birlikte
gider. Harita agdan gonderilmedigi (iki taraf ayni tohumdan urettigi) ve
uretim modlanabilir veriden turedigi icin, mod kumeleri farkli olan iki
oyuncu ayni tohumdan FARKLI dunya uretir. Bu yuzden parmak izi tutmayan
baglanti reddedilir.
